# Christian Ambrosio Digital Solutions

Projeto limpo em React + Vite, pronto para publicar no GitHub Pages.

## Rodar localmente

```bash
npm install
npm run dev
```

## Publicar no GitHub Pages

1. Suba estes arquivos para um repositório no GitHub.
2. Vá em `Settings > Pages`.
3. Em `Build and deployment`, escolha `GitHub Actions`.
4. Vá em `Actions` e rode o workflow `Deploy GitHub Pages`.

O workflow gera a pasta `dist` e publica automaticamente.
